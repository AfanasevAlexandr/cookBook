# Telegram Mini App — Кулинарная книга

Статический фронтенд без сборщиков — размещается на GitHub Pages как есть.
Сделано на основе шаблона каталога магазина: убран функционал корзины,
заказа и мультиязычности; вместо товаров — рецепты, вместо категорий
товаров — листы Google Таблицы.

## Структура

```
index.html              главная страница
css/styles.css          все стили, адаптация под тему Telegram
js/config.js            URL Apps Script — ЗАПОЛНИТЬ
js/api.js               загрузка книги рецептов (с кэшем в localStorage)
js/catalog.js           фильтрация, рендер списка, разбор ингредиентов/шагов
js/app.js               точка входа, склеивает всё вместе
gas/Code.gs             код для Google Apps Script (вставляется в таблицу)
sample-data.json        тестовые данные из вашей таблицы — для локальной проверки
```

## Модель данных

Каждый **лист** Google Таблицы — это **категория** рецептов. Название
листа = название категории в приложении (поэтому в `Кулинарная_книга.xlsx`
категории — это "Панкейки", "Блины", "Супы" и т.д. — переименовывать
листы не нужно, просто заполняйте их рецептами).

В каждом листе одна и та же таблица из 4 колонок:

| Название блюда | Ингредиенты | Способ приготовления | Примечания |
|---|---|---|---|

- **Ингредиенты** — пункты через `;` (можно переносить строку внутри
  ячейки для читаемости — перенос игнорируется при разборе).
- **Способ приготовления** — каждый шаг с новой строки внутри ячейки
  (Alt+Enter в Google Sheets). Нумерацию в начале строки можно не
  писать — приложение пронумерует шаги само; если она есть — тоже
  ок, будет убрана автоматически.
- **Примечания** — необязательно, если пусто — блок не показывается.

Чтобы добавить новую категорию — просто добавьте новый лист с такими
же 4 колонками в заголовке. Ничего в коде менять не нужно.

Лист, чьё название начинается с `_` или `.`, игнорируется — можно
использовать для черновиков/заметок в той же таблице.

## Что нужно сделать перед запуском

1. Открыть `Кулинарная_книга.xlsx` (или её копию) как Google Таблицу.
2. Расширения → Apps Script → вставить содержимое `gas/Code.gs`.
3. Deploy → New deployment → тип "Web app":
   - Execute as: **Me**
   - Who has access: **Anyone**
4. Скопировать URL вида `https://script.google.com/macros/s/XXXXX/exec`
   и вставить его в `js/config.js` → `CATALOG_API_URL`.
5. Залить содержимое папки (`index.html`, `css/`, `js/`) в корень
   репозитория на GitHub → включить GitHub Pages
   (Settings → Pages → Source: main / root).
   `gas/Code.gs` и `sample-data.json` в репозиторий заливать не
   обязательно — это вспомогательные файлы, не часть фронтенда.
6. В BotFather у вашего бота: `/newapp` или `/setmenubutton` → указать
   URL вида `https://ВАШ_ЛОГИН.github.io/ВАШ_РЕПОЗИТОРИЙ/`.

**Важно:** при каждом изменении `Code.gs` нужно создавать НОВУЮ версию
деплоя (Deploy → Manage deployments → Edit → New version), иначе
фронтенд продолжит получать старую версию скрипта по тому же URL.

## Проверка локально, без Apps Script

Можно посмотреть интерфейс уже сейчас, на данных из вашей таблицы,
без деплоя Apps Script:

1. В `js/config.js` временно замените `CATALOG_API_URL` на `'./sample-data.json'`.
2. Запустите локальный сервер в папке проекта, например:
   `python3 -m http.server 8080`
   (открыть просто как файл `file://` не получится — модули `type="module"`
   браузер заблокирует).
3. Откройте `http://localhost:8080` в браузере.
4. Не забудьте вернуть `CATALOG_API_URL` на реальный URL Apps Script
   перед деплоем на GitHub Pages.

Внутри Telegram тема/цвета подтянутся из `Telegram.WebApp` автоматически;
в обычном браузере используются цвета по умолчанию из `css/styles.css`.

## Дальнейшие доработки (по желанию)

- Фото блюд: если решите добавить, можно ввести 5-ю колонку `image_url`
  в каждый лист — понадобится небольшая правка `Code.gs` и `catalog.js`.
- Доп. поля (время готовки, порции, сложность): добавляются так же —
  новая колонка в листах + пара строк в `Code.gs`/`catalog.js`/`app.js`.
- Избранное/последние просмотренные — можно хранить в localStorage
  по аналогии с тем, как раньше хранилась корзина.
